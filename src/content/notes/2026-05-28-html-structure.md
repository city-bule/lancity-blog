## 这篇笔记记录什么

这篇笔记记录我第一次系统整理 HTML 页面结构时的理解。

## 我学到了什么

1. HTML 负责页面内容和结构。
2. `head` 里放页面信息，`body` 里放用户能看到的内容。
3. 使用语义化标签可以让页面更容易维护。

## 我的理解

网页就像一份文档，标题、段落、列表和图片都需要放在合适的位置。结构清楚以后，再使用 CSS 做样式会轻松很多。
